# 大盤小報

前台目前可選，**只出橫式**，30 fps。直式自 2026-10-22 起關閉（程式與畫面保留未刪；恢復方式見 `run.js` 的 `DAPAN_RENDER_PORTRAIT` 與 `render-motion.js` 的 `TEMPLATE_MOTION.dapan.p.off`，兩處要一起改）。

| 版本 | 尺寸 | 畫面安排 |
|---|---|---|
| 直式（已關閉） | 1080×1920（9:16） | 1 秒開場卡顯示日期與標題，接續主播、字幕與截圖 |
| 橫式 | 1920×1080（16:9） | 直接開始主段；主播在左側，日期與標題常駐右側面板 |

兩版共用同一支主播影片、字幕、配圖時間軸與背景音樂。標題可換行，前台提供兩行、每行約 10 字的參考。

字幕樣式（2026-11-11 起）：橫式用明體字幕——思源宋體 Black 白字、每句半透明黑底框、置中於講者區；配圖計畫頁標的重點詞依前後字眼變色（漲／增／買超→紅，跌／減／賣超／虧→綠，其餘金），整支最多 6 句自動加金色筆刷底線（數字優先、間隔至少 8 秒）。直式（已關閉）保留原本的黑體字幕。實作見 [明體字幕](../../90_系統/應用程式/src/DapanXiaobao/SerifSubtitles.tsx) 與 [規則](../../90_系統/應用程式/src/DapanXiaobao/serif-emphasis.ts)。

截圖段與動態（2026-11-12 起）：哪張圖配哪幾句、卡片裁哪一塊、金框框哪裡、小標題，以及動態小影片放哪（開頭一段、結尾總結一段，整支 2 段）都由 Claude 排（不用標注頁），排好就直接出片；Claude 沒排成功時整支標成失敗並寫出原因，按「重新出片」再試（可以在那裡寫給 Claude 的指示，只影響重出的那一支）。橫式呈現為浮動 UI 卡片：模糊暖色背景、白色小標題、圓角卡片、金色發光框（同一張卡講好幾項時跟著旁白往下移）、同段換圖左右輪播；講大盤指數時卡片包含上方走勢圖。細節見 [OCR與配圖設定](../../90_系統/維護說明/OCR與配圖設定.md)。
