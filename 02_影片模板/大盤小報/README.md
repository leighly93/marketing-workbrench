# 大盤小報

前台目前可選，一次製作產出直式與橫式，均為 30 fps。

| 版本 | 尺寸 | 畫面安排 |
|---|---|---|
| 直式 | 1080×1920（9:16） | 1 秒開場卡顯示日期與標題，接續主播、字幕與截圖 |
| 橫式 | 1920×1080（16:9） | 直接開始主段；主播在左側，日期與標題常駐右側面板 |

兩版共用同一支主播影片、字幕、配圖時間軸與背景音樂。標題可換行，前台提供兩行、每行約 9 字的參考。
