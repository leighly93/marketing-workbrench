# 大盤小報

前台目前可選，**只出橫式**，30 fps。直式自 2026-10-22 起關閉（程式與畫面保留未刪；恢復方式見 `run.js` 的 `DAPAN_RENDER_PORTRAIT` 與 `render-motion.js` 的 `TEMPLATE_MOTION.dapan.p.off`，兩處要一起改）。

| 版本 | 尺寸 | 畫面安排 |
|---|---|---|
| 直式（已關閉） | 1080×1920（9:16） | 1 秒開場卡顯示日期與標題，接續主播、字幕與截圖 |
| 橫式 | 1920×1080（16:9） | 直接開始主段；主播在左側，日期與標題常駐右側面板 |

兩版共用同一支主播影片、字幕、配圖時間軸與背景音樂。建立工作的標題只填一行（2026-11-12 起），出片時 Claude 切成兩行（`scripts/claude-title.js`，跟 HeyGen 平行跑；只決定切點、不能改字，接起來跟原標題不一樣就不用）。橫式右側標題第一句白、其餘黃，基準 74px；一句太長（會縮到 58px 以下）就在畫面上折成兩行、顏色不變，最長那行決定整組字級（數字裡的逗號不當切點）；Claude 沒切成功時在最靠近中間的標點拆成兩句（沒有標點就不拆）。舊工作的兩行標題照原樣。

字幕樣式（2026-11-11 起）：橫式用明體字幕樣式——白字（2026-11-12 起字型改思源黑體 900，使用者覺得明體難閱讀；明體檔仍留在 public/）、每句半透明黑底框、置中於講者區；配圖計畫頁標的重點詞依前後字眼變色（漲／增／買超→紅，跌／減／賣超／虧→綠，其餘金），整支最多 6 句自動加金色筆刷底線（數字優先、間隔至少 8 秒）。直式（已關閉）保留原本的黑體字幕。實作見 [明體字幕](../../90_系統/應用程式/src/DapanXiaobao/SerifSubtitles.tsx) 與 [規則](../../90_系統/應用程式/src/DapanXiaobao/serif-emphasis.ts)。

截圖段與動態（2026-11-12 起）：哪張圖配哪幾句、卡片裁哪一塊、金框框哪裡、小標題，以及動態小影片放哪（開頭一段、結尾總結一段，整支 2 段；結尾那段延續到影片結束當收尾。動態卡片內容由 Claude 產生，格式不合格或數字對不上原文都會重產一次，第二次還不行那段才不做）都由 Claude 排（不用標注頁），排好就直接出片，成品檔名是「建立日期 YYMMDD_標題.mp4」；Claude 沒排成功時整支標成失敗並寫出原因，按「重新出片」再試（可以在那裡寫給 Claude 的指示，只影響重出的那一支）。橫式呈現為浮動 UI 卡片：模糊暖色背景、白色小標題 72px（貼在卡片正上方）、圓角卡片、金色發光框（同一張卡講好幾項時跟著旁白往下移）、同段換圖左右輪播（連續幾張每張講不到 1.5 秒、疊起來每張還有 560px 寬時，改成上下疊在同一個畫面，一張張由下往上加進來，金框只在最新那張；小標題取幾張共同的字，例如「漲停」，沒有就跟著最新那張換）；講大盤指數時卡片包含上方走勢圖；卡片背景不放金色星點（2026-11-12 使用者）；單張卡片太窄（顯示寬不到 700px，例如整頁營收）又有金框時，先給完整畫面 0.8 秒，之後每句推近到那句的框附近（寬放到最大、上下以框為中心，0.45 秒），金框推完才淡入（2026-11-13 環球晶營收）；同一句話裡最後一張圖會留到那句講完。細節見 [OCR與配圖設定](../../90_系統/維護說明/OCR與配圖設定.md)。
