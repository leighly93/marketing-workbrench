# 美股焦點

前台目前可選。直式 1080×1920（9:16）、30 fps。

以 1 秒開場卡呈現日期與標題，接續主播、字幕及截圖，主段保留品牌圖層。標題可換行，前台提供兩行、每行約 10 字的參考。整體規格照[盤中焦點](../盤中焦點/README.md)複製一份，差別在素材與主播設定。

## 看素材

[固定素材資料夾](../../共用素材/美股焦點)：`intro-frame.jpg` 是開場底圖、`header-overlay.png` 是主段品牌圖層、`bgm.wav` 是背景音樂。日期與稿件標題由程式疊上。

日期牌的座標是對著這兩張圖重新量的，沒有沿用盤中焦點：美股焦點的招牌是圓角膠囊、盤中焦點是斜切梯形，空白區位置與大小都不同。換新美術要回到[畫面組合](../../90_系統/應用程式/src/UsStock/UsStockComposition.tsx)重量一次。
