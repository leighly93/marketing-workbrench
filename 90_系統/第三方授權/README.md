# 第三方字型

Noto Sans TC 可變字型來自 [Google Fonts 官方目錄](https://github.com/google/fonts/tree/main/ofl/notosanstc)，使用原檔 `NotoSansTC[wght].ttf`，存為 `public/NotoSansTC-VF.ttf`；支援 400 與 700 等字重。
