# 第三方字型

Noto Sans TC 可變字型來自 [Google Fonts 官方目錄](https://github.com/google/fonts/tree/main/ofl/notosanstc)，使用原檔 `NotoSansTC[wght].ttf`，存為 `public/NotoSansTC-VF.ttf`；支援 400 與 700 等字重。

授權原文：[SIL Open Font License](NotoSansTC-OFL.txt)。

SHA-256：`864727d210d54f2537bbe23b3a839436c3992af72de9322af5270897246bd44f`。

Noto Serif TC Black（思源宋體 Black，2.002）用於大盤小報橫式字幕，原檔 `NotoSerifTC-Black.ttf` 只做 WOFF2 壓縮、保留完整字集，存為 `public/NotoSerifTC-Black.woff2`。不裁字：常用字表缺很多股票名用字。

授權原文：[SIL Open Font License](NotoSerifTC-OFL.txt)。

SHA-256：原檔 `370753764af16638d4bd36a55ac9bffdfc39472966aa6a87697fb10390f6c9b6`；WOFF2 `58772a6af4eb7ab9c6f33d2a177cbe309e2de11d9777020b5830f3ccf840e51f`。
