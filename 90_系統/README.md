# 系統與開發入口

先讀[整理狀態](整理狀態.md)，只按目前任務查閱需要的文件。

| 位置 | 用途 |
| --- | --- |
| [應用程式](應用程式/) | 網頁前後端、影片模板、OCR／字幕產線、套件及設定；真正的 npm 專案 |
| [維護說明](維護說明/) | 已核對的 [OCR 與配圖設定](維護說明/OCR與配圖設定.md)、[啟動與驗證](維護說明/啟動與驗證.md)、[影片交付規格](維護說明/影片交付規格.md)、[內網網址參考](維護說明/內網固定網址設定.md) |
| [資料](資料/) | 發音詞庫、股票簡稱、配圖記憶、留言、修正及頁型樣本；正式資料，不能當暫存清理 |
| [測試](測試/) | 使用合成資料驗證路徑與服務讀寫 |
| [paths.js](paths.js) | 程式根／工作資料根、CLI 路徑與歷史樣本引用解析 |
| [工作儲存.js](工作儲存.js) | 按完整 job ID 定位中文工作目錄、稿件、素材與製作資料 |
| [執行.js](執行.js) | 根目錄 npm 命令轉送，保留參數與呼叫者的 CWD |

原 `docs/` 已拆除，程式實作也已集中。`應用程式/server/public/` 放網頁的 HTML／CSS／JavaScript；`應用程式/public/` 放 Remotion 執行素材，兩者用途不同。

`工作紀錄/` 集中每次製作的 MP4、稿件、素材與製作資料；品牌素材在 `共用素材/`，產線輸出在 `90_系統/暫存/產線輸出/`。完整 ID 由 `工作儲存.js` 定位；工作與影片關係見[使用說明](維護說明/工作與影片位置.md)。

歷史 JSONL 與頁型資料中的 `docs/page-samples/...` 原文保留。讀取引用時使用 `resolveDataReference(root, reference)`；新寫入資料使用 `dataPath(root, ...)` 與相對根目錄的新路徑。這不需要建立舊目錄或符號連結。

環境與驗證入口在 `環境/`；按 [啟動與驗證](維護說明/啟動與驗證.md) 完成 setup、init、doctor、verify。執行資料、封存與研究／整合歷史留在本機，公開副本不含這些歷史內容。

引擎介面、版本觀測與容器重建範圍見 [環境與 Adapter](維護說明/環境與Adapter.md)。
