# 目前範圍與後續工作

第一版範圍：清楚的工作資料夾、模板導覽、前後端與產線集中、可重建的開發環境，以及供 Agent 接手的最小文件。

## 已固定的契約

- 每次製作是一筆完整 ID 的工作，MP4、稿件、素材與製作資料集中保存，不自動依年代刪除。
- 程式與資料根分離；共用素材獨立，產線暫存不是正式成品。
- README 以 Mermaid 運作流程開場，再以橫向 Input／Output 與三個內部步驟展開自動化影片產出，接續技術／模板預覽與資料夾結構；不放逐步操作教學。
- 公開 Git 不含私人工作、封存、執行記憶、留言或憑證；初始化只補缺檔，既有資料不覆寫。
- 開發入口為 setup、init、doctor、verify；Claude 與其他 Agent 共用 AGENTS.md，按任務讀取文件。

## v1.0.0 前的 Harness 邊界

- 服務與出片只面向 macOS；Linux Docker 僅作程式驗證，不是部署目標。
- OCR 維持既有 Adapter；字幕已指定 whisper.cpp Base Q5_1、CPU、4 執行緒、中文，透過 Adapter 轉成既有逐字資料。
- 字幕出片前會檢查時間軸；判定壞掉就擋下來（不寫回 subtitles.json），並在音檔前墊靜音換 whisper 的 30 秒 window 邊界重轉一次。第一次一律不墊，維持既有結果；兩次都壞就停在出片前交給人，不再自動重試。
- 工作可以「重新出片」：沿用原稿件、素材、標注與講者影片再跑一次，一律 skipGenerate，不重新呼叫 HeyGen／MiniMax。新工作停在 draft 等人確認標注；稿件不給改（標注以字元索引定位）。
- 開發容器固定基底 digest，使用已提交檔案建置；CI 在無外網容器執行合成資料驗證，GitHub Actions 固定提交 SHA。
- `.nvmrc`、`.node-version` 與容器使用相同 Node 版本；whisper.cpp 原始碼與模型鎖 SHA-256，setup:whisper 安裝於專案 .cache。
- 已以獨立約 5.5 秒中文合成音訊實測 CPU／4 執行緒，確認輸出與逐字時間可轉成既有字幕格式；這不代表歷史成品品質回歸。
- 原生乾淨機完整還原與歷史樣本成品質量仍未驗收，不宣稱所有工具都已重建。
- v1.0.0 tag／Release 尚未發布；完成環境邊界對齊後再定版。

## 第一版不包含

- 既有網站切換、自動部署、付費生成與真實工作重跑。
- 工作列表最新 50 筆以外的瀏覽改善、缺件提示完整改版、跨 job 版本模型。
- 待辨識備份／試片的進一步分類，以及舊工作缺失檔案還原。
- 外部 API 有效性、Whisper 模型下載與端到端付費產線驗收。
- 墊靜音改成每支都跑的預設值：只在單支上驗證過（墊 0.5／1.2 秒都把壞掉的時間軸修回正常），沒有拿歷史工作批量回測，改預設會動到所有影片的字幕斷句。
- 重新出片的「改稿也保留標注」：標注用 `startCharIdx`／`endCharIdx` 定位，稿件一改就整段錯位且不會報錯。要支援得先換成錨點字串比對。

涉及以上範圍，先描述具體影響再依使用者新指示進行。舊任務與一次性交接文件不繼承為未完成授權。
