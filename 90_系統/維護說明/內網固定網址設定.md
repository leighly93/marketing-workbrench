# 內網網址與服務位置

第一版預設 `HOST=127.0.0.1`、`PORT=4000`，只供本機存取。`mkt-video.local` 是既有電腦的內網設定，不是 Git clone 後自動提供的網址。

需要讓同事連線時，先確認哪個副本要提供服務、目前是否已有服務佔用 port，以及防火牆與區網範圍。將該副本根 `.env` 的 HOST 設為 `0.0.0.0`，並設定自己的 ADMIN_KEY；不要使用或分享舊預設密碼。

`npm run studio` 經由 `server/start.js` 載入根 `.env`；直接執行 `server/index.js` 不會載入該設定檔。所有路徑以 [啟動與驗證](啟動與驗證.md) 為準。

以下腳本會改變電腦的自動啟動或網路設定，必須有對應的部署授權才執行；setup、init、verify 都不會呼叫它們：

- `90_系統/應用程式/server/install-autostart.sh`：macOS 自動啟動。
- `90_系統/應用程式/server/setup-lan-domain.sh`：既有內網名稱設定。

第一版交付沒有切換原網站、安裝 LaunchAgent 或修改 hosts。不要將同時啟動兩份工作台視為無副作用的測試。
