# 工作與影片位置

每次製作仍是一筆 job，完整 ID 不變；人看的資料集中在同一個中文工作資料夾。

```text
工作紀錄/
└── 日期_影片名稱_完整jobID/
    ├── 直式.mp4
    ├── 橫式.mp4
    ├── 稿件.txt
    ├── 素材/
    └── _製作資料/
        ├── job.json
        ├── 快照/
        └── 備份/
```

只保留實際存在的影片與稿件，不替缺件建立空檔。投廣輸出另標「投廣版」，同名再次輸出加 `(2)` 避免覆蓋；這不代表已有正式版本模型。

## 網頁如何找到影片

1. 服務掃描 [工作紀錄](../../工作紀錄/) 中各資料夾的 `_製作資料/job.json`，以內部完整 ID 建立對照。
2. 網頁從 `/api/jobs` 取得列表，再以 `/api/jobs/<ID>` 選取工作。目前列表仍只顯示最新 50 筆，全部 55 筆都保存在資料夾中。
3. 播放器沿用 `/api/jobs/<ID>/file/<輸出名稱>`；伺服器依該 job 的 `outputs[].archive` 取得其資料夾第一層的 MP4。輸出 API 名稱保持相容，例如 `output-dapan.mp4` 可對應 `直式.mp4`。
4. 缺件只查同工作的製作輸出、縮圖、快照與素材，仍找不到回 404；不使用共用產線暫存的同名影片。

`archive` 欄位指正式影片引用，與 `99_封存/` 不同。舊缺片引用保留原文以供追查；`done` 只表示曾完成，不能證明影片仍在。

## 產線與備份

- [共用素材](../../共用素材/) 供多筆工作使用，製作時複製到程式工作區。
- 新輸出先寫 產線暫存（本機資料），確認為當次產出後保存到該工作第一層，再更新 job 引用。
- 工作備份保存在該工作 `_製作資料/備份/`；獨立 CLI 沒有工作 ID 時寫入系統的 `製作備份/未指定工作/`。
- 待辨識（本機資料） 保存目前無法唯一確認歸屬的備份與原輸出／試片，全部保留，不能當成缺件工作的成品。
- 工作稿件、素材、成品、備份與快照不再依年代自動刪除；明確的管理者刪除工作操作仍會移除整筆工作。

工具用途、操作流程與資料夾導覽見根目錄 [README](../../README.md)；介紹簡報也位於根目錄。
